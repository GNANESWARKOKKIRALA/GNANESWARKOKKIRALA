## 🚀 Featured Projects

### 🤖 AI RAG Chatbot
A retrieval-augmented generation chatbot that lets users query documents through natural conversation. Combines semantic search over a vector store with LLM-generated responses, backed by persistent chat memory and user authentication.

- 🔍 Semantic search over embedded documents
- 🧠 Vector database retrieval with ChromaDB
- ⚡ LLM integration via the Groq API
- 💬 Persistent chat memory across sessions
- 🔐 User authentication

**Tech:** Python • FastAPI • ChromaDB • SQLite • Groq API

---

### 🏋️ AI Fitness Assistant
An AI-driven fitness companion that generates personalized workout and diet plans, tracks progress over time, and answers fitness questions through a built-in chatbot — all wrapped in a clean Streamlit interface.

- 🗓️ AI-generated workout planner
- 🥗 Personalized diet recommendations
- ⚖️ BMI calculator
- 📈 Progress tracking dashboard
- 🤖 Conversational AI fitness chatbot

**Tech:** Python • Streamlit • SQL • LLM (Groq/LLaMA 3.3)

---

### 🎨 AI Air Canvas
A computer-vision drawing tool that turns hand gestures into on-screen strokes — no mouse or stylus required. Tracks fingertip movement in real time to let users draw directly in the air.

- ✋ Real-time hand gesture recognition
- 🎥 Live webcam-based drawing canvas
- 🧩 Built with OpenCV & MediaPipe

**Tech:** Python • OpenCV • MediaPipe
